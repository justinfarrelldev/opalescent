# Task 13 affine ownership evidence

Implemented affine resource ownership and second-class borrow checking in the type checker.

Key behavior covered:
- Local `affine resource` declarations register noncopyable owner types.
- Affine owners move into owned parameters and reject use-after-move.
- Affine owners cannot escape through return, break/continue payloads, assignment, constructor fields, arrays, or lambda captures.
- `ref` and `mutable ref` call-site borrow arguments are second-class and valid only for the matching parameter mode/full expression.
- Terminal proposal test gate registers core prerequisite affine resources without opening public terminal imports or adding runtime/codegen behavior.
